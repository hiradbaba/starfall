# STARFALL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the 2019 Windows console shooter as STARFALL, a browser game for a portfolio. It plays like the original, looks neo-retro and has tests, CI and a GitHub Pages deploy.

**Architecture:** A pure, DOM-free game core (`step(state, input) → { state, events }`) runs at a fixed tick rate. Thin browser layers sit around it: canvas rendering of a character grid with effects, Web Audio synthesis, keyboard and touch input that both produce one `InputFrame` per tick, and a small screen state machine. Storage goes through a fault-tolerant key-value wrapper. A lint rule enforces the core/browser boundary.

**Tech Stack:** TypeScript 6.0 (strict), Vite 8, Canvas 2D, Web Audio, Vitest 5, Playwright 1.64, ESLint 10 + typescript-eslint 8, Prettier 3, GitHub Actions and GitHub Pages.

These are situations the spec implies but no unit test exercises. Each one is covered by a Playwright test in Task 9 (`e2e/smoke.spec.ts`):

1. **Typing a pilot name containing game keys** (`m`, space, `p`, `x`): this must not mute, fire or pause. Only Escape leaves the field.

```ts
// mulberry32: tiny seeded PRNG whose whole state is one uint32,
// so it can live inside GameState and be saved.
export interface Roll {
  value: number;
  rng: number;
}

export function nextFloat(rng: number): Roll {
  const next = (rng + 0x6d2b79f5) >>> 0;
  let t = next;
  t = Math.imul(t ^ (t >>> 15), t | 1);
  t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
  return { value: ((t ^ (t >>> 14)) >>> 0) / 4294967296, rng: next };
}

/** Integer in [0, max). */
export function nextInt(rng: number, max: number): Roll {
  const roll = nextFloat(rng);
  return { value: Math.floor(roll.value * max), rng: roll.rng };
}
```

Create `src/core/progression.ts`:

```ts
import { KILLS_PER_LEVEL, MIN_TICK_MS, TICK_STEP_MS } from './config';

export interface Progress {
  level: number;
  greenCount: number;
  specialCount: number;
  tickMs: number;
}

export function levelFor(score: number): number {
  return Math.floor(score / KILLS_PER_LEVEL);
}

/**
 * Applies every level gained since `progress.level`, one at a time, so a
 * multi-level jump gets the full difficulty increase (2019 bug #8).
 */
export function applyLevelUps(
  progress: Progress,
  score: number,
): { progress: Progress; gained: number[] } {
  const p = { ...progress };
  const gained: number[] = [];
  const target = levelFor(score);
  while (p.level < target) {
    p.level += 1;
    p.greenCount += 2;
    if (p.level % 2 === 0) p.specialCount += 2;
    if (p.level % 3 === 0) p.tickMs = Math.max(MIN_TICK_MS, p.tickMs - TICK_STEP_MS);
    gained.push(p.level);
  }
  return { progress: p, gained };
}
```

```ts
import type { EnemyKind, ShotKind } from './state';

/** Do horizontal spans [ax, ax+aw) and [bx, bx+bw) share a cell? */
export function overlapsX(ax: number, aw: number, bx: number, bw: number): boolean {
  return ax < bx + bw && bx < ax + aw;
}

/**
 * Swept vertical test for two things that each moved this tick: true when
 * they end on the same row or swapped order (passed through each other).
 */
export function crossedY(prevA: number, nextA: number, prevB: number, nextB: number): boolean {
  return nextA === nextB || Math.sign(prevA - prevB) !== Math.sign(nextA - nextB);
}

export function canKill(shot: ShotKind, enemy: EnemyKind): boolean {
  return (shot === 'normal' && enemy === 'green') || (shot === 'special' && enemy === 'special');
```

```ts
import { COLS, ENEMY_WIDTH } from './config';
import { nextInt } from './rng';
import type { Enemy, EnemyKind } from './state';

const SAME_KIND_GAP = { x: 3, y: 3 };
const OTHER_KIND_GAP = { x: 6, y: 4 };

export interface Wave {
  enemies: Enemy[];
  rng: number;
  nextId: number;
  /** Rows the wave occupies above the screen; the next wave is due after this many ticks. */
  height: number;
}

function tooClose(a: { x: number; y: number }, b: Enemy, kind: EnemyKind): boolean {
  const gap = b.kind === kind ? SAME_KIND_GAP : OTHER_KIND_GAP;
  return Math.abs(a.x - b.x) < gap.x && Math.abs(a.y - b.y) < gap.y;
}

/**
 * Places `count` enemies in a band of 2*count rows directly above the screen.
 * Samples only from cells that are still free, so it never retries or spins
 * (2019 bug #11). Places fewer if the band fills up.
 */
export function placeWave(
  kind: EnemyKind,
  count: number,
  existing: readonly Enemy[],
  rng: number,
  nextId: number,
): Wave {
  const height = count * 2;
  let free: { x: number; y: number }[] = [];
  for (let y = -height; y <= -1; y++) {
    for (let x = 0; x <= COLS - ENEMY_WIDTH; x++) {
      const cell = { x, y };
      if (!existing.some((e) => tooClose(cell, e, kind))) free.push(cell);
    }
  }

  const enemies: Enemy[] = [];
  for (let i = 0; i < count && free.length > 0; i++) {
    const roll = nextInt(rng, free.length);
    rng = roll.rng;
    const cell = free[roll.value]!;
    const enemy: Enemy = { id: nextId++, kind, x: cell.x, y: cell.y };
    enemies.push(enemy);
    free = free.filter((c) => !tooClose(c, enemy, kind));
  }
  return { enemies, rng, nextId, height };
}
```

```ts
import {
  COLS,
  ENEMY_WIDTH,
  PLAYER_WIDTH,
  ROWS,
  RPG_RANGE,
  SHOT_OFFSET,
  SPECIAL_FROM_LEVEL,
} from './config';
import { canKill, crossedY, overlapsX } from './collide';
import { applyLevelUps } from './progression';
import { placeWave } from './spawn';
import type { EnemyKind, GameState, InputFrame, ShotKind } from './state';

export type GameEvent =
  | { type: 'shot'; kind: ShotKind }
  | { type: 'rpgLaunched' }
  | { type: 'rpgDetonated'; x: number; y: number; kills: number }
  | { type: 'enemyKilled'; kind: EnemyKind; x: number; y: number }
  | { type: 'levelUp'; level: number }
  | { type: 'playerHit'; x: number; y: number };

export interface StepResult {
  state: GameState;
  events: GameEvent[];
}

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));

/** Advances the game by one tick. Pure: never mutates `prev`. */
export function step(prev: GameState, input: InputFrame): StepResult {
  if (prev.over) return { state: prev, events: [] };
  const s = structuredClone(prev);
  const events: GameEvent[] = [];
  s.tick += 1;

  // 1. Player moves (the world always advances too — 2019 bug #1).
  const prevPlayerY = s.player.y;
  s.player.x = clamp(s.player.x + input.dx, 0, COLS - PLAYER_WIDTH);
  s.player.y = clamp(s.player.y + input.dy, 0, ROWS - 1);

  // 2. Weapons spawn at the ship's nose.
  const fire = (kind: ShotKind) => {
    s.shots.push({ id: s.nextId++, kind, x: s.player.x + SHOT_OFFSET, y: s.player.y });
    events.push({ type: 'shot', kind });
  };
  if (input.fire) fire('normal');
  if (input.special) fire('special');
  if (input.rpg && s.rpg === null && s.rpgCharges > 0) {
    s.rpg = { x: s.player.x + SHOT_OFFSET, y: s.player.y, travelled: 0 };
    s.rpgCharges -= 1;
    events.push({ type: 'rpgLaunched' });
  }

  // 3. Everything moves one row.
  const prevShotY = new Map(s.shots.map((b) => [b.id, b.y]));
  const prevEnemyY = new Map(s.enemies.map((e) => [e.id, e.y]));
  for (const b of s.shots) b.y -= 1;
  for (const e of s.enemies) e.y += 1;
  if (s.rpg) {
    s.rpg.y -= 1;
    s.rpg.travelled += 1;
  }

  // 4. Shots vs enemies (swept, one hitbox rule — bugs #2/#3).
  const killed = new Set<number>();
  const spent = new Set<number>();
  for (const b of s.shots) {
    for (const e of s.enemies) {
      if (killed.has(e.id) || !canKill(b.kind, e.kind)) continue;
      if (!overlapsX(b.x, 1, e.x, ENEMY_WIDTH)) continue;
      if (!crossedY(prevShotY.get(b.id)!, b.y, prevEnemyY.get(e.id)!, e.y)) continue;
      killed.add(e.id);
      spent.add(b.id);
      events.push({ type: 'enemyKilled', kind: e.kind, x: e.x, y: e.y });
      break;
    }
  }

  // 5. RPG detonates after RPG_RANGE rows of travel, hitting on-screen enemies only (bug #7).
  if (s.rpg && (s.rpg.travelled >= RPG_RANGE || s.rpg.y <= 0)) {
    let kills = 0;
    for (const e of s.enemies) {
      if (killed.has(e.id) || e.y < 0 || e.y >= ROWS) continue;
      killed.add(e.id);
      kills += 1;
      events.push({ type: 'enemyKilled', kind: e.kind, x: e.x, y: e.y });
    }
    events.push({ type: 'rpgDetonated', x: s.rpg.x, y: s.rpg.y, kills });
    s.rpg = null;
  }

  // 6. Dead things are removed, not flagged (bugs #4/#16).
  s.enemies = s.enemies.filter((e) => !killed.has(e.id) && e.y < ROWS);
  s.shots = s.shots.filter((b) => !spent.has(b.id) && b.y >= 0);

  // 7. Enemy vs player (swept).
  for (const e of s.enemies) {
    if (!overlapsX(s.player.x, PLAYER_WIDTH, e.x, ENEMY_WIDTH)) continue;
    if (!crossedY(prevPlayerY, s.player.y, prevEnemyY.get(e.id)!, e.y)) continue;
    s.over = true;
    events.push({ type: 'playerHit', x: s.player.x, y: s.player.y });
    break;
  }

  // 8. Every kill scores; every level gained applies (bugs #6/#8).
  s.score += killed.size;
  const { progress, gained } = applyLevelUps(
    { level: s.level, greenCount: s.greenCount, specialCount: s.specialCount, tickMs: s.tickMs },
    s.score,
  );
  Object.assign(s, progress);
  for (const level of gained) events.push({ type: 'levelUp', level });

  // 9. Next wave is due as soon as the previous band has fully entered (bug #10).
  if (!s.over) {
    spawnIfDue(s, 'green', s.greenCount);
    if (s.level >= SPECIAL_FROM_LEVEL) spawnIfDue(s, 'special', s.specialCount);
  }

  return { state: s, events };
}

function spawnIfDue(s: GameState, kind: EnemyKind, count: number): void {
  if (s.tick < s.nextWave[kind]) return;
  const wave = placeWave(kind, count, s.enemies, s.rng, s.nextId);
  s.enemies.push(...wave.enemies);
  s.rng = wave.rng;
  s.nextId = wave.nextId;
  s.nextWave[kind] = s.tick + wave.height;
}
```

```ts
export interface HighScore {
  runId: number;
  name: string;
  score: number;
  level: number;
}

export const MAX_SCORES = 5;
const SCORES_VERSION = 1;

/**
 * Records a run's score. A run that already has an entry (saved earlier via
 * Save & Quit) is updated rather than duplicated. Returns the 0-based rank,
 * or null if the run didn't make the table.
 */
export function recordScore(
  list: readonly HighScore[],
  entry: HighScore,
): { list: HighScore[]; rank: number | null } {
  if (entry.score <= 0) return { list: [...list], rank: null };
  const previous = list.find((h) => h.runId === entry.runId);
  const best = previous && previous.score >= entry.score ? previous : entry;
  const others = list.filter((h) => h.runId !== entry.runId);
  // Stable sort: on equal scores the earlier entry keeps the higher rank.
  const sorted = [...others, best].sort((a, b) => b.score - a.score).slice(0, MAX_SCORES);
  const rank = sorted.indexOf(best);
  return { list: sorted, rank: rank === -1 ? null : rank };
}

export function serialiseScores(list: readonly HighScore[]): string {
  return JSON.stringify({ version: SCORES_VERSION, scores: list });
}

export function deserialiseScores(raw: string | null): HighScore[] {
  if (raw === null) return [];
  try {
    const parsed: unknown = JSON.parse(raw);
    if (typeof parsed !== 'object' || parsed === null) return [];
    const { version, scores } = parsed as { version?: unknown; scores?: unknown };
    if (version !== SCORES_VERSION || !Array.isArray(scores)) return [];
    return scores.filter(isHighScore).slice(0, MAX_SCORES);
  } catch {
    return [];
  }
}

function isHighScore(v: unknown): v is HighScore {
  if (typeof v !== 'object' || v === null) return false;
  const h = v as Record<string, unknown>;
  return (
    Number.isSafeInteger(h.runId) &&
    typeof h.name === 'string' &&
    h.name.length > 0 &&
    Number.isSafeInteger(h.score) &&
    Number.isSafeInteger(h.level)
  );
}
```

```ts
export interface KeyValueStore {
  get(key: string): string | null;
  set(key: string, value: string): void;
  remove(key: string): void;
}

export function memoryStore(): KeyValueStore {
  const data = new Map<string, string>();
  return {
    get: (k) => data.get(k) ?? null,
    set: (k, v) => void data.set(k, v),
    remove: (k) => void data.delete(k),
  };
}

/**
 * Wraps a Web Storage object so that every failure (private mode, quota,
 * disabled storage) degrades to "nothing persisted" instead of crashing.
 */
export function safeStore(getBacking: () => Storage | undefined): KeyValueStore {
  const attempt = <T>(fn: (s: Storage) => T, fallback: T): T => {
    try {
      const backing = getBacking();
      return backing ? fn(backing) : fallback;
    } catch {
      return fallback;
    }
  };
  return {
    get: (k) => attempt((s) => s.getItem(k), null),
    set: (k, v) => attempt((s) => s.setItem(k, v), undefined),
    remove: (k) => attempt((s) => s.removeItem(k), undefined),
  };
}
```

```ts
import { recordScore, deserialiseScores, serialiseScores, type HighScore } from './core/highscores';
import { deserialise, serialise } from './core/save';
import type { GameState } from './core/state';
import type { KeyValueStore } from './storage';

export const KEYS = {
  save: 'starfall.save',
  scores: 'starfall.highscores',
  muted: 'starfall.muted',
} as const;

export function loadSave(store: KeyValueStore): GameState | null {
  const state = deserialise(store.get(KEYS.save));
  if (state === null) store.remove(KEYS.save);
  return state;
}

export function loadScores(store: KeyValueStore): HighScore[] {
  return deserialiseScores(store.get(KEYS.scores));
}

function record(store: KeyValueStore, state: GameState): number | null {
  const { list, rank } = recordScore(loadScores(store), {
    runId: state.runId,
    name: state.pilot,
    score: state.score,
    level: state.level,
  });
  store.set(KEYS.scores, serialiseScores(list));
  return rank;
}

/** Save & Quit: persist the full run and count its score so far (2019 bugs #13/#15). */
export function saveAndQuit(store: KeyValueStore, state: GameState): number | null {
  store.set(KEYS.save, serialise(state));
  return record(store, state);
}

/** Game over: the run can no longer be continued (2019 bug #12). */
export function finishGame(store: KeyValueStore, state: GameState): number | null {
  store.remove(KEYS.save);
  return record(store, state);
}
```

```ts
import type { InputFrame } from '../core/state';

type Action = 'fire' | 'special' | 'rpg' | 'pause';

const MOVES: Record<string, readonly [number, number]> = {
  ArrowLeft: [-1, 0],
  KeyA: [-1, 0],
  ArrowRight: [1, 0],
  KeyD: [1, 0],
  ArrowUp: [0, -1],
  KeyW: [0, -1],
  ArrowDown: [0, 1],
  KeyS: [0, 1],
};

const ACTIONS: Record<string, Action> = {
  Space: 'fire',
  KeyC: 'special',
  KeyX: 'rpg',
  Escape: 'pause',
  KeyP: 'pause',
};

/** Actions that keep firing every tick while held. RPG and pause need a fresh press. */
const REPEATING: ReadonlySet<Action> = new Set(['fire', 'special']);

export function isGameKey(code: string): boolean {
  return code in MOVES || code in ACTIONS;
}

/**
 * Turns key (or virtual touch-button) presses into one InputFrame per tick.
 * Presses that start and end between two ticks are latched so they're never lost.
 */
export class KeyState {
  private held = new Set<string>();
  private pressed = new Set<Action>();

  down(code: string): void {
    if (!isGameKey(code)) return;
    const action = ACTIONS[code];
    if (action && !this.held.has(code)) this.pressed.add(action);
    this.held.add(code);
  }

  up(code: string): void {
    this.held.delete(code);
  }

  clear(): void {
    this.held.clear();
    this.pressed.clear();
  }

  poll(): InputFrame {
    let dx = 0;
    let dy = 0;
    const heldActions = new Set<Action>();
    for (const code of this.held) {
      const move = MOVES[code];
      if (move) {
        dx += move[0];
        dy += move[1];
      }
      const action = ACTIONS[code];
      if (action && REPEATING.has(action)) heldActions.add(action);
    }
    const active = (a: Action) => this.pressed.has(a) || heldActions.has(a);
    const frame: InputFrame = {
      dx: Math.sign(dx) as InputFrame['dx'],
      dy: Math.sign(dy) as InputFrame['dy'],
      fire: active('fire'),
      special: active('special'),
      rpg: active('rpg'),
      pause: active('pause'),
    };
    this.pressed.clear();
    return frame;
  }
}
```

```ts
import type { KeyState } from './keyboard';

const BUTTONS = [
  { code: 'ArrowUp', label: '▲', area: 'up' },
  { code: 'ArrowLeft', label: '◀', area: 'left' },
  { code: 'ArrowRight', label: '▶', area: 'right' },
  { code: 'ArrowDown', label: '▼', area: 'down' },
  { code: 'Space', label: 'FIRE', area: 'fire' },
  { code: 'KeyC', label: 'SPEC', area: 'special' },
  { code: 'KeyX', label: 'RPG', area: 'rpg' },
  { code: 'KeyP', label: 'II', area: 'pause' },
] as const;

/**
 * On-screen controls for touch devices. Each button presses a virtual key on
 * the shared KeyState, so touch and keyboard go through the same input path.
 * CSS only shows `.touch` on coarse pointers.
 */
export function mountTouchControls(root: HTMLElement, keys: KeyState): void {
  const pad = document.createElement('div');
  pad.className = 'touch';
  pad.setAttribute('aria-hidden', 'true');
  for (const b of BUTTONS) {
    const el = document.createElement('button');
    el.type = 'button';
    el.textContent = b.label;
    el.style.gridArea = b.area;
    el.className = `touch-btn touch-${b.area}`;
    const release = () => keys.up(b.code);
    el.addEventListener('pointerdown', (e) => {
      e.preventDefault();
      el.setPointerCapture(e.pointerId);
      keys.down(b.code);
    });
    el.addEventListener('pointerup', release);
    el.addEventListener('pointercancel', release);
    pad.append(el);
  }
  root.append(pad);
}
```

```ts
import { COLS, ROWS } from '../core/config';

export const HUD_ROWS = 2;
export const VIEW_COLS = COLS;
export const VIEW_ROWS = ROWS + HUD_ROWS;
/** Monospace glyphs are roughly 0.6 as wide as they are tall. */
const CHAR_ASPECT = 0.6;

export const COLORS = {
  bg: '#04050c',
  cyan: '#5ef6ff',
  green: '#5dff8a',
  magenta: '#ff5ef1',
  white: '#f4f7ff',
  red: '#ff4d5e',
  yellow: '#ffd84d',
  dim: '#56648a',
} as const;

export interface Layout {
  cellW: number;
  cellH: number;
  offsetX: number;
  offsetY: number;
}

/** Breathing room around the grid, in CSS pixels. */
const MARGIN = 12;

/** Largest grid of VIEW_COLS x VIEW_ROWS cells that fits inside the margin, centred. */
export function fitGrid(width: number, height: number): Layout {
  const w = Math.max(0, width - MARGIN * 2);
  const h = Math.max(0, height - MARGIN * 2);
  const cellH = Math.min(h / VIEW_ROWS, w / (VIEW_COLS * CHAR_ASPECT));
  const cellW = cellH * CHAR_ASPECT;
  return {
    cellW,
    cellH,
    offsetX: (width - cellW * VIEW_COLS) / 2,
    offsetY: (height - cellH * VIEW_ROWS) / 2,
  };
}

/** Converts a pixel position to the grid cell under it. */
export function cellAt(layout: Layout, px: number, py: number): { col: number; row: number } {
  return {
    col: Math.floor((px - layout.offsetX) / layout.cellW),
    row: Math.floor((py - layout.offsetY) / layout.cellH),
  };
}

const FONT = '"SF Mono", Menlo, Consolas, "DejaVu Sans Mono", "Liberation Mono", monospace';

/** Draws text on the character grid. Columns and rows may be fractional (interpolation). */
export class View {
  layout: Layout = { cellW: 1, cellH: 1, offsetX: 0, offsetY: 0 };
  width = 0;
  height = 0;
  shake = { x: 0, y: 0 };

  constructor(readonly ctx: CanvasRenderingContext2D) {}

  resize(cssWidth: number, cssHeight: number, dpr: number): void {
    const canvas = this.ctx.canvas;
    canvas.width = Math.round(cssWidth * dpr);
    canvas.height = Math.round(cssHeight * dpr);
    this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    this.width = cssWidth;
    this.height = cssHeight;
    this.layout = fitGrid(cssWidth, cssHeight);
  }

  clear(): void {
    this.ctx.fillStyle = COLORS.bg;
    this.ctx.fillRect(0, 0, this.width, this.height);
  }

  x(col: number): number {
    return this.layout.offsetX + col * this.layout.cellW + this.shake.x;
  }

  y(row: number): number {
    return this.layout.offsetY + row * this.layout.cellH + this.shake.y;
  }

  /** Draws each character in its own cell so box-drawing glyphs line up. */
  text(col: number, row: number, s: string, color: string, glow = 10): void {
    const { ctx, layout } = this;
    ctx.font = `${Math.floor(layout.cellH * 0.9)}px ${FONT}`;
    ctx.textBaseline = 'middle';
    ctx.textAlign = 'center';
    ctx.fillStyle = color;
    ctx.shadowColor = color;
    ctx.shadowBlur = glow;
    const chars = [...s];
    for (let i = 0; i < chars.length; i++) {
      ctx.fillText(chars[i]!, this.x(col + i) + layout.cellW / 2, this.y(row) + layout.cellH / 2);
    }
    ctx.shadowBlur = 0;
  }

  centered(row: number, s: string, color: string, glow = 10): void {
    this.text(Math.floor((VIEW_COLS - [...s].length) / 2), row, s, color, glow);
  }

  /** Frame around the playfield. */
  frame(color: string): void {
    const { ctx, layout } = this;
    ctx.strokeStyle = color;
    ctx.globalAlpha = 0.35;
    ctx.lineWidth = 1;
    ctx.strokeRect(this.x(0), this.y(0), layout.cellW * COLS, layout.cellH * ROWS);
    ctx.globalAlpha = 1;
  }
}
```

```ts
import { COLS, ROWS } from '../core/config';
import { COLORS, type View } from './grid';

interface Star {
  x: number;
  y: number;
  speed: number;
  bright: number;
}

interface Particle {
  x: number;
  y: number;
  vx: number;
  vy: number;
  life: number;
  max: number;
  color: string;
}

const STAR_COUNT = 70;

/**
 * Purely cosmetic layer: starfield, particles, screen shake, CRT overlay.
 * Positions are in grid cells; speeds in cells per second.
 */
export class Effects {
  stars: Star[] = [];
  particles: Particle[] = [];
  private shakeLeft = 0;
  private shakeMag = 0;

  constructor(
    readonly reducedMotion: boolean,
    private random: () => number = Math.random,
  ) {
    for (let i = 0; i < STAR_COUNT; i++) {
      const layer = i % 3;
      this.stars.push({
        x: random() * COLS,
        y: random() * ROWS,
        speed: [1.5, 4, 9][layer]!,
        bright: [0.25, 0.5, 0.9][layer]!,
      });
    }
  }

  burst(col: number, row: number, color: string, count = 14): void {
    const n = this.reducedMotion ? Math.ceil(count / 3) : count;
    for (let i = 0; i < n; i++) {
      const angle = this.random() * Math.PI * 2;
      const speed = 4 + this.random() * 10;
      const max = 300 + this.random() * 400;
      this.particles.push({
        x: col,
        y: row,
        vx: Math.cos(angle) * speed,
        vy: Math.sin(angle) * speed * 0.6,
        life: max,
        max,
        color,
      });
    }
  }

  shake(magnitude: number, ms: number): void {
    if (this.reducedMotion) return;
    this.shakeMag = Math.max(this.shakeMag, magnitude);
    this.shakeLeft = Math.max(this.shakeLeft, ms);
  }

  shakeOffset(): { x: number; y: number } {
    if (this.shakeLeft <= 0) return { x: 0, y: 0 };
    return {
      x: (this.random() * 2 - 1) * this.shakeMag,
      y: (this.random() * 2 - 1) * this.shakeMag,
    };
  }

  update(dtMs: number): void {
    const dt = dtMs / 1000;
    const drift = this.reducedMotion ? 0.3 : 1;
    for (const s of this.stars) {
      s.y += s.speed * dt * drift;
      if (s.y >= ROWS) {
        s.y -= ROWS;
        s.x = this.random() * COLS;
      }
    }
    for (const p of this.particles) {
      p.x += p.vx * dt;
      p.y += p.vy * dt;
      p.life -= dtMs;
    }
    this.particles = this.particles.filter((p) => p.life > 0);
    this.shakeLeft = Math.max(0, this.shakeLeft - dtMs);
    if (this.shakeLeft === 0) this.shakeMag = 0;
  }

  drawStars(view: View): void {
    const { ctx, layout } = view;
    for (const s of this.stars) {
      ctx.globalAlpha = s.bright;
      ctx.fillStyle = COLORS.white;
      const size = Math.max(1, layout.cellW * 0.12 * (s.speed / 4));
      ctx.fillRect(view.x(s.x), view.y(s.y), size, size);
    }
    ctx.globalAlpha = 1;
  }

  drawParticles(view: View): void {
    const { ctx, layout } = view;
    for (const p of this.particles) {
      ctx.globalAlpha = p.life / p.max;
      ctx.fillStyle = p.color;
      ctx.shadowColor = p.color;
      ctx.shadowBlur = 8;
      const size = layout.cellW * 0.25;
      ctx.fillRect(view.x(p.x + 0.5), view.y(p.y + 0.5), size, size);
    }
    ctx.globalAlpha = 1;
    ctx.shadowBlur = 0;
  }

  /** Scanlines + vignette over everything. */
  drawCrt(view: View): void {
    const { ctx, width, height } = view;
    ctx.fillStyle = 'rgba(0, 0, 0, 0.22)';
    for (let y = 0; y < height; y += 3) ctx.fillRect(0, y, width, 1);
    const g = ctx.createRadialGradient(
      width / 2,
      height / 2,
      Math.min(width, height) * 0.35,
      width / 2,
      height / 2,
      Math.max(width, height) * 0.75,
    );
    g.addColorStop(0, 'rgba(0,0,0,0)');
    g.addColorStop(1, 'rgba(0,0,0,0.65)');
    ctx.fillStyle = g;
    ctx.fillRect(0, 0, width, height);
  }
}
```

```ts
const SEMITONES: Record<string, number> = { C: -9, D: -7, E: -5, F: -4, G: -2, A: 0, B: 2 };

/** Frequency of a note like "A4", "C#5" or "Bb3" (A4 = 440 Hz). */
export function noteFreq(note: string): number {
  const m = /^([A-G])([#b]?)(\d)$/.exec(note);
  if (!m) throw new Error(`Bad note: ${note}`);
  const [, letter, accidental, octave] = m;
  const semis =
    SEMITONES[letter!]! +
    (accidental === '#' ? 1 : accidental === 'b' ? -1 : 0) +
    (Number(octave) - 4) * 12;
  return 440 * 2 ** (semis / 12);
}
```

```ts
import { noteFreq, THEME } from './theme';

export type Sound =
  'move' | 'select' | 'shot' | 'special' | 'rpgLaunch' | 'rpgBoom' | 'explode' | 'levelUp' | 'hit';

type Wave = OscillatorType;

/**
 * All sound is synthesised with Web Audio — no files. The AudioContext is
 * created on the first user gesture (browser autoplay rules).
 */
export class AudioEngine {
  private ctx: AudioContext | null = null;
  private master: GainNode | null = null;

  constructor(public muted: boolean) {}

  unlock(): void {
    if (this.ctx) {
      void this.ctx.resume();
      return;
    }
    try {
      this.ctx = new AudioContext();
      this.master = this.ctx.createGain();
      this.master.gain.value = this.muted ? 0 : 0.35;
      this.master.connect(this.ctx.destination);
    } catch {
      this.ctx = null;
    }
  }

  setMuted(muted: boolean): void {
    this.muted = muted;
    if (this.master) this.master.gain.value = muted ? 0 : 0.35;
  }

  play(sound: Sound): void {
    switch (sound) {
      case 'move':
        return this.tone(300, 60, 'square', 0.15);
      case 'select':
        return this.tone(500, 120, 'square', 0.2);
      case 'shot':
        return this.tone(880, 50, 'square', 0.08, 0, 440);
      case 'special':
        return this.tone(330, 90, 'sawtooth', 0.12, 0, 660);
      case 'rpgLaunch':
        return this.tone(200, 250, 'triangle', 0.25, 0, 900);
      case 'rpgBoom':
        return this.noise(600, 0.6);
      case 'explode':
        return this.noise(160, 0.25);
      case 'levelUp':
        this.tone(523, 90, 'square', 0.15);
        this.tone(659, 90, 'square', 0.15, 90);
        return this.tone(784, 160, 'square', 0.15, 180);
      case 'hit':
        this.noise(700, 0.7);
        return this.tone(220, 700, 'sawtooth', 0.3, 0, 40);
    }
  }

  /** Plays the original theme; returns its length in ms. */
  playTheme(bpm = 132): number {
    const beat = 60_000 / bpm;
    let at = 0;
    for (const [note, beats] of THEME) {
      if (note) this.tone(noteFreq(note), beats * beat * 0.9, 'square', 0.18, at);
      at += beats * beat;
    }
    return at;
  }

  private tone(
    freq: number,
    ms: number,
    type: Wave,
    gain: number,
    delayMs = 0,
    slideTo?: number,
  ): void {
    const { ctx, master } = this;
    if (!ctx || !master) return;
    const t0 = ctx.currentTime + delayMs / 1000;
    const t1 = t0 + ms / 1000;
    const osc = ctx.createOscillator();
    const env = ctx.createGain();
    osc.type = type;
    osc.frequency.setValueAtTime(freq, t0);
    if (slideTo) osc.frequency.exponentialRampToValueAtTime(slideTo, t1);
    env.gain.setValueAtTime(gain, t0);
    env.gain.exponentialRampToValueAtTime(0.001, t1);
    osc.connect(env).connect(master);
    osc.start(t0);
    osc.stop(t1);
  }

  private noise(ms: number, gain: number): void {
    const { ctx, master } = this;
    if (!ctx || !master) return;
    const length = Math.floor((ctx.sampleRate * ms) / 1000);
    const buffer = ctx.createBuffer(1, length, ctx.sampleRate);
    const data = buffer.getChannelData(0);
    for (let i = 0; i < length; i++) data[i] = (Math.random() * 2 - 1) * (1 - i / length);
    const src = ctx.createBufferSource();
    const env = ctx.createGain();
    src.buffer = buffer;
    env.gain.value = gain;
    src.connect(env).connect(master);
    src.start();
  }
}
```

```ts
import { COLORS, type View } from '../render/grid';
import { isConfirm, isDown, isUp, type App } from './app';

export interface MenuItem {
  label: string;
  enabled: boolean;
  run(): void;
}

/** Vertical list of options with a cursor, keyboard and tap support. */
export class MenuList {
  index: number;

  constructor(
    private app: App,
    private items: MenuItem[],
    private firstRow: number,
  ) {
    this.index = Math.max(
      0,
      items.findIndex((i) => i.enabled),
    );
  }

  draw(view: View): void {
    this.items.forEach((item, i) => {
      const selected = i === this.index;
      const label = selected ? `▶ ${item.label} ◀` : item.label;
      const color = !item.enabled ? COLORS.dim : selected ? COLORS.yellow : COLORS.cyan;
      view.centered(this.firstRow + i * 2, label, color, selected ? 14 : 6);
    });
  }

  keyDown(code: string): void {
    if (isUp(code)) this.move(-1);
    else if (isDown(code)) this.move(1);
    else if (isConfirm(code)) this.choose(this.index);
  }

  tap(row: number): void {
    const i = (row - this.firstRow) / 2;
    if (Number.isInteger(i) && i >= 0 && i < this.items.length) this.choose(i);
  }

  private move(delta: number): void {
    const n = this.items.length;
    let i = this.index;
    for (let k = 0; k < n; k++) {
      i = (i + delta + n) % n;
      if (this.items[i]!.enabled) break;
    }
    if (i !== this.index) {
      this.index = i;
      this.app.audio.play('move');
      this.app.announce(this.items[i]!.label);
    }
  }

  private choose(i: number): void {
    const item = this.items[i]!;
    if (!item.enabled) return;
    this.index = i;
    this.app.audio.play('select');
    item.run();
  }
}
```

```ts
import { COLS, ROWS } from '../core/config';
import type { GameState, Point } from '../core/state';
import { step, type GameEvent } from '../core/step';
import { isGameKey } from '../input/keyboard';
import { COLORS, type View } from '../render/grid';
import { finishGame, saveAndQuit } from '../session';
import type { App, KeyPress, Screen } from './app';
import { gameOverScreen } from './gameover';
import { menuScreen } from './menu';
import { MenuList } from './menuList';

export const GLYPHS = {
  player: '[═Ω═]',
  green: '├☼┤',
  special: '╠╧╣',
  normal: '|',
  specialShot: '║',
  rpg: '■',
} as const;

/** How long the explosion plays before the game-over screen. */
const DEATH_MS = 1000;
const BANNER_MS = 1500;

const lerp = (a: number, b: number, t: number) => a + (b - a) * t;

type Tracked = Point & { id: number };

/** Position between last tick and this one, so motion is smooth at any frame rate. */
function between(before: ReadonlyMap<number, Point>, item: Tracked, t: number): Point {
  const p = before.get(item.id) ?? item;
  return { x: lerp(p.x, item.x, t), y: lerp(p.y, item.y, t) };
}

export function playScreen(app: App, initial: GameState): Screen {
  let state = initial;
  let prev = initial;
  let acc = 0;
  let paused = false;
  let deathLeft = DEATH_MS;
  let rank: number | null = null;
  let banner = { text: '', left: 0 };
  app.keys.clear();

  const resume = () => {
    paused = false;
    app.keys.clear();
  };
  const pause = () => {
    if (paused || state.over) return;
    paused = true;
    app.keys.clear();
    pauseMenu.index = 0;
    app.announce('Paused');
  };
  const pauseMenu = new MenuList(
    app,
    [
      {
        label: 'RESUME',
        enabled: true,
        run: resume,
      },
      {
        label: 'SAVE & QUIT',
        enabled: true,
        run: () => {
          saveAndQuit(app.store, state);
          app.go(menuScreen(app));
        },
      },
      { label: 'QUIT WITHOUT SAVING', enabled: true, run: () => app.go(menuScreen(app)) },
    ],
    14,
  );

  const react = (events: GameEvent[]) => {
    for (const e of events) {
      switch (e.type) {
        case 'shot':
          app.audio.play(e.kind === 'normal' ? 'shot' : 'special');
          break;
        case 'enemyKilled':
          app.fx.burst(e.x + 1, e.y, e.kind === 'green' ? COLORS.green : COLORS.magenta);
          app.audio.play('explode');
          break;
        case 'rpgLaunched':
          app.audio.play('rpgLaunch');
          break;
        case 'rpgDetonated':
          app.fx.burst(e.x, e.y, COLORS.yellow, 60);
          app.fx.shake(8, 450);
          app.audio.play('rpgBoom');
          break;
        case 'levelUp':
          banner = { text: `LEVEL ${e.level}`, left: BANNER_MS };
          app.audio.play('levelUp');
          app.announce(`Level ${e.level}`);
          break;
        case 'playerHit':
          app.fx.burst(e.x + 2, e.y, COLORS.cyan, 50);
          app.fx.shake(12, 800);
          app.audio.play('hit');
          rank = finishGame(app.store, state);
          break;
      }
    }
  };

  const updateHud = () =>
    app.hud(
      `Score ${state.score} · Level ${state.level} · RPG ${state.rpgCharges} · Pilot ${state.pilot}`,
    );
  updateHud();
  app.announce(`Launch! Pilot ${state.pilot}.`);

  return {
    name: 'play',

    update(dt) {
      banner.left = Math.max(0, banner.left - dt);
      if (paused) return;
      if (state.over) {
        deathLeft -= dt;
        if (deathLeft <= 0) app.go(gameOverScreen(app, state, rank));
        return;
      }
      acc += dt;
      while (acc >= state.tickMs && !state.over) {
        acc -= state.tickMs;
        const frame = app.keys.poll();
        if (frame.pause) {
          pause();
          return;
        }
        prev = state;
        const result = step(state, frame);
        state = result.state;
        react(result.events);
        updateHud();
      }
    },

    draw(view: View) {
      const t = state.over ? 1 : Math.min(1, acc / state.tickMs);
      view.frame(COLORS.cyan);
      const { ctx } = view;
      ctx.save();
      ctx.beginPath();
      ctx.rect(view.x(0), view.y(0), view.layout.cellW * COLS, view.layout.cellH * ROWS);
      ctx.clip();

      const prevEnemies = new Map(prev.enemies.map((e) => [e.id, e]));
      for (const e of state.enemies) {
        const p = between(prevEnemies, e, t);
        view.text(
          p.x,
          p.y,
          e.kind === 'green' ? GLYPHS.green : GLYPHS.special,
          e.kind === 'green' ? COLORS.green : COLORS.magenta,
        );
      }
      const prevShots = new Map(prev.shots.map((b) => [b.id, b]));
      for (const b of state.shots) {
        const p = between(prevShots, b, t);
        view.text(
          p.x,
          p.y,
          b.kind === 'normal' ? GLYPHS.normal : GLYPHS.specialShot,
          b.kind === 'normal' ? COLORS.white : COLORS.red,
        );
      }
      if (state.rpg) {
        const from = prev.rpg ?? { ...state.rpg, y: state.rpg.y + 1 };
        view.text(state.rpg.x, lerp(from.y, state.rpg.y, t), GLYPHS.rpg, COLORS.yellow, 16);
      }
      if (!state.over) {
        view.text(
          lerp(prev.player.x, state.player.x, t),
          lerp(prev.player.y, state.player.y, t),
          GLYPHS.player,
          COLORS.cyan,
          14,
        );
      }
      ctx.restore();

      const rpgs = GLYPHS.rpg.repeat(state.rpgCharges).padEnd(3, '·');
      view.text(0, ROWS, `SCORE ${state.score}`, COLORS.yellow, 6);
      view.text(14, ROWS, `LEVEL ${state.level}`, COLORS.yellow, 6);
      view.text(26, ROWS, `RPG ${rpgs}`, COLORS.yellow, 6);
      view.text(0, ROWS + 1, `PILOT ${state.pilot}`, COLORS.dim, 0);
      view.text(COLS - 18, ROWS + 1, 'SPC C X · P pause', COLORS.dim, 0);

      if (banner.left > 0) view.centered(10, banner.text, COLORS.yellow, 20);
      if (paused) {
        ctx.fillStyle = 'rgba(4, 5, 12, 0.75)';
        ctx.fillRect(0, 0, view.width, view.height);
        view.centered(10, 'P A U S E D', COLORS.cyan, 16);
        pauseMenu.draw(view);
      }
    },

    keyDown(key: KeyPress) {
      if (paused) {
        if (key.code === 'Escape' || key.code === 'KeyP') resume();
        else pauseMenu.keyDown(key.code);
        return;
      }
      if (!key.repeat && isGameKey(key.code)) app.keys.down(key.code);
    },

    keyUp(code) {
      app.keys.up(code);
    },

    tap(_col, row) {
      if (paused) pauseMenu.tap(row);
    },

    blur: pause,

    leave() {
      app.keys.clear();
    },
  };
}
```

```js
// Records a short gameplay GIF for the README: node scripts/capture-gif.mjs
// Needs a running preview server (npm run preview) on port 4173.
import { writeFileSync } from 'node:fs';
import { chromium } from '@playwright/test';
import gifenc from 'gifenc';
import { PNG } from 'pngjs';

const { GIFEncoder, quantize, applyPalette } = gifenc;
const URL = process.env.URL ?? 'http://localhost:4173/';
const OUT = 'docs/media/gameplay.gif';
const FRAMES = 60;
const FRAME_MS = 80;

const browser = await chromium.launch();
const page = await browser.newPage({ viewport: { width: 560, height: 420 } });
await page.goto(URL);
await page.keyboard.press('Enter');
await page.locator('#pilot').fill('Hirad');
await page.keyboard.press('Enter');
await page.waitForTimeout(1500);

const gif = GIFEncoder();
await page.keyboard.down('Space');
const moves = ['ArrowLeft', 'ArrowRight'];
for (let i = 0; i < FRAMES; i++) {
  if (i % 12 === 0) {
    await page.keyboard.up(moves[(i / 12 + 1) % 2]);
    await page.keyboard.down(moves[(i / 12) % 2]);
  }
  if (i === 30) await page.keyboard.press('KeyX');
  const png = PNG.sync.read(await page.screenshot());
  const palette = quantize(png.data, 64);
  gif.writeFrame(applyPalette(png.data, palette), png.width, png.height, {
    palette,
    delay: FRAME_MS,
  });
}
gif.finish();
writeFileSync(OUT, gif.bytes());
await browser.close();
console.log(`Wrote ${OUT}`);
```

````
# STARFALL

A neo-retro terminal space shooter that runs in the browser. It's a 2026 rebuild of **"Star Wars"**, a C++ console game I wrote in 2019.

**[▶ Play it](https://hiradbaba.github.io/starfall/)**

![Gameplay](docs/media/gameplay.gif)

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | Arrow keys / WASD | D-pad |
| Fire (kills green ships) | Space | FIRE |
| Special shot (kills magenta ships) | C | SPEC |
| RPG: clears the screen, 3 per game | X | RPG |
| Pause / Save & Quit | P or Esc | II |
| Mute | M | |

You level up every 10 kills. Each level brings more ships; magenta ships appear from level 2, and every third level is faster.

## 2019 → 2026

The original was a single 700-line `PRO.cpp` for the Windows console. It used `conio.h` to read keys, `SetConsoleCursorPosition` to draw and `Beep()` for the music:

```cpp
if(_kbhit()){
    a=_getch();
    if(a==UP && me.y>0){
        me.y--;
    }
    ...
    goxy(copy.x,copy.y);
    printf("     ");
    continue;   // ← skips the rest of the frame: enemies freeze while you hold a key
}
```

The rebuild keeps the same game: the same three weapons, the same enemy types, the same level curve, pilot names, save/continue and a high score. The code is now organised into layers:

- `src/core/`: the game as pure TypeScript functions. `step(state, input) → { state, events }` advances one tick. There is no DOM in this layer; a lint rule enforces that, and every rule has a unit test.
- `src/render/`: a canvas character grid with CRT scanlines, glow, particles, screen shake and a parallax starfield.
- `src/audio/`: Web Audio synthesis, so there are no audio files. It plays an original theme.
- `src/input/`: keyboard and touch both produce the same per-tick `InputFrame`.
- `src/screens/`: the menu, name entry, play, pause, game over and high-score screens.

### Bugs in my 2019 logic, and how they're fixed

| # | 2019 bug | Fix |
|---|---|---|
| 1 | Holding a key froze the world (`continue` skipped the update) | The world advances every tick |
| 2 | An enemy and the ship could swap rows without colliding | Swept collision |
| 3 | Bullets tunnelled through enemies, and the two shot types had different hitboxes | Swept collision with one hitbox rule |
| 4 | Dead enemies (`x = NULL`) kept falling and could kill you at the left edge | Dead entities are removed |
| 5 | Special-enemy loops ran over `en.n` instead of `spen.n`, which created ghost enemies | Separate collections |
| 6 | Several kills in one tick scored only 1 | Every kill counts |
| 7 | The RPG scored off-screen enemies and detonated at an absolute row | Scores on-screen kills only and detonates after 10 rows of travel |
| 8 | Jumping several levels at once applied the difficulty only once | Applied per level |
| 9 | The tick delay went negative around level 15, so `Sleep()` hung the game | 40 ms floor |
| 10 | Gaps between waves | The next wave is queued as soon as the last one enters the screen |
| 11 | `srand(time)` was reseeded every wave, so waves repeated, and the overlap retry loop could spin | One seeded RNG, sampling only free cells |
| 12 | Continue could resume a game you'd already lost | The save is cleared on game over |
| 13 | Continue lost the level and speed | The full state is saved |
| 14 | Missing files crashed the game; long names overflowed a buffer; spaces in names broke the save | Validated JSON storage and bounded names |
| 15 | The high score was only checked on death | Also checked on Save & Quit |
| 16 | Bullet arrays never shrank and overflowed after 10,000 shots | Off-screen bullets are removed |

Each fix has a regression test in `tests/core/`.
````
